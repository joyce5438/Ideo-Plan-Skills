# Ideo Plan

跨領域的題材探索與文章規劃技能。它以適量、重視來源品質的初步調查，發現值得追問的問題，提出方向與暫定架構，並與使用者討論。研究出現重大新發現時，重新討論方向；不強迫套用固定文章模板。

根目錄的 `SKILL.md` 與 `references/` 是唯一維護來源。修改後執行 `bash scripts/sync-skill-packages.sh`，再執行 `bash scripts/check-skill-packages.sh`。特殊語法是給模型的指令，並非可執行程式或結果保證。

## 安裝與更新

Codex：

```text
codex plugin marketplace add and install joyce5438/Ideo-Plan-Skills
codex plugin marketplace upgrade ideo-plan
```

Claude Code：

```text
/plugin marketplace add joyce5438/Ideo-Plan-Skills
/plugin install ideo-plan@ideo-plan

```
